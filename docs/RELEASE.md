## Синхронизация исходников и deployment

Исходники и документация архивируются из актуального `main`. Точный финальный
коммит и SHA-256 архивов фиксируются в отчёте сдачи; `SHA256SUMS.txt` лежит
рядом с архивами. Handoff содержит документацию и переносимый плагин, source ZIP
содержит исходники, включая `tests/products.test.ts`. Старый `codex-review.zip`
сохранён отдельно как исторический снимок до исправления кнопок.

Alpic отслеживает `main`: существующий проект, Root Directory `./`, Node.js 24,
build `npm run build`, Streamable HTTP. После push проверяется SHA текущего
deployment. Если автодеплой не завершился, требуется дождаться его завершения
или, при ошибке, проверить build logs существующего проекта. Новый проект,
домен и изменение Supabase для этой поставки не нужны.

Персональный `.app.json`, `.env`, секреты, зависимости, временные файлы и
review-архив исключены из Git и финальных ZIP. Локальные персональные файлы
сохранены. Проверка SHA bundle подтверждает соответствие React локальной сборке;
установка на втором аккаунте и визуальная приёмка остаются отдельными проверками.

Записи live не проверялись: нужен отдельно разрешённый сценарий и тестовая
корзина/окружение. Не запускайте add/update/remove на общей корзине ради теста.
Данные и схема Supabase в этой работе не изменялись.
