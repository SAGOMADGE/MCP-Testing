# Установка в ChatGPT

Документация проверена 19 ноября 2026 года. Названия кнопок зависят от клиента.
Доступ зависит от прав аккаунта/workspace. Импорт ZIP не доказывает работу MCP/UI.

## A. Переносимый ZIP

1. На компьютере войдите в нужный ChatGPT аккаунт/workspace.
2. Установите доступный **Plugin Creator** из каталога.
3. В Work-чате выберите `@Plugin Creator`, прикрепите `shopping-cart-1.0.2.zip`:

   > Создай приватный плагин из архива, сохрани MCP endpoint, переносимый manifest
   > и shopping-assistant. Не публикуй в публичный каталог. Покажи diagnostics,
   > ссылку и файлы. Если такой плагин уже создан, сначала найди его и обнови
   > существующий экземпляр, не создавай дубликат.

4. Откройте карточку → **Install / Установить**, затем **Connect / Подключить**,
   если предлагается. Сервер использует **No authentication**.
5. Проверьте наличие Skill и MCP-соединения. В **новом** чате выберите плагин
   через `@` и выполните приёмку ниже.

В workspace с правом ZIP upload можно вместо шага 3 использовать Admin console →
нужный workspace → Plugins → Add → Upload plugin. Это не универсальная кнопка
для любого аккаунта. [Официальная инструкция](https://help.openai.com/en/articles/20001256-plugins-in-chatgpt).

Если карточка есть, а инструментов нет, проверьте Install, Connect, новый чат,
права и diagnostics. Не подставляйте App ID автора. Если импорт оставил только
Skill или Desktop only, используйте маршрут B.

## B. Своя регистрация сервера и Skill в том же плагине

Это дополнительная настройка в аккаунте получателя, **не установка ZIP одним
действием**. Основа — официальный Add custom MCP server и ранее проверенное
автором добавление Skill в App-backed плагин. На аккаунте Нугзара требуется приёмка.

1. Откройте https://chatgpt.com/plugins → **+ → Add custom MCP server**.
2. Название: `Shopping Cart MCP`. Server URL:
   `https://mcp-testing-5679d679.alpic.live/mcp`.
   Authentication: **No authentication**. Туннель не нужен.
3. Прочитайте уведомление сервиса и выберите **Create as a plugin**.
4. Установите/подключите созданный плагин. Должны обнаружиться шесть инструментов:
   `get-products`, `get-product-details`, `get-cart`, `add-to-cart`,
   `update-cart-item`, `remove-from-cart`.
5. Скопируйте **ссылку на свою карточку**. Через её **Edit Plugin** или
   `@Plugin Creator` прикрепите `shopping-assistant-1.0.2.zip` и отправьте:

   > Обнови существующий плагин по ссылке [вставьте свою ссылку]. Добавь
   > skills/shopping-assistant/SKILL.md из архива как установленный Agent Skill,
   > сохранив текст. Сначала прочитай текущие файлы. Сохрани ID плагина, его
   > собственную App-привязку, соединение, presentation и аудиторию. Повысь версию.
   > Не создавай второй плагин и не используй read_skill вместо установки Skill.

6. Проверьте файл Skill в новой версии и начните новый чат.

ID создаётся сервисом в аккаунте получателя. Не конструируйте `.app.json` из
чужого ID и не меняйте префиксы вручную: используйте фактически найденную привязку.
[Регистрация](https://developers.openai.com/plugins/quickstart),
[проверка подключения](https://developers.openai.com/plugins/deploy/connect-chatgpt).

Если аккаунт не разрешает добавить MCP или редактировать Skill, маршрут недоступен.
Минимальный обход, если разрешён: MCP-плагин и отдельный Skill-плагин в одном чате.
Это **не единая установка**. Вставка SKILL.md в чат также не равна установленному Skill.

## Приёмка без изменения корзины

В новом чате выберите именно установленный плагин:

1. «Покажи каталог. Не меняй корзину»: фактический `get-products`, реальные товары,
   React-каталог в поддерживаемом клиенте.
2. «Покажи подробности первого товара»: `get-product-details`, ID из каталога.
3. «Покажи общую демо-корзину и её сумму»: `get-cart`.
4. «Прочитай установленный Agent Skill shopping-assistant, покажи путь к файлу
   и последнее правило Important rules. Не вызывай read_skill». Ожидается правило
   о Scenario Modeler в React UI, а не отдельном MCP Tool.
5. В React: фильтр, «Подробнее», «Посмотреть корзину», «Спланировать покупки».
   Не нажимайте добавление/удаление при проверке без записи.

Запишите клиент/версию, тариф без персональных данных, дату и результат каждого
пункта. Старый TEST автора не заменяет приёмку на аккаунте получателя.

## Мобильное «Использовать на компьютере»

OpenAI выделяет **Desktop only**, недоступные на мобильном устройстве. Конкретные
возможности также зависят от аккаунта, региона и workspace. Бесплатный тариф сам
по себе не доказывает причину сообщения. [Доступность](https://learn.chatgpt.com/docs/plugins).

Сравните одну карточку в desktop и mobile: Desktop only, MCP connection, Skill,
diagnostics импорта. Если удалённый MCP всё равно помечен desktop-only, передайте
эти сведения поддержке OpenAI. В нашем пакете нет локального сервера или hooks.
Причина сообщения на втором аккаунте **экспериментально не установлена**.
