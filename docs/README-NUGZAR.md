# Нугзару: Shopping Cart MCP

Каталог, подробности товаров и общая демо-корзина. Сервер и React UI находятся
на Alpic; компьютер разработчика не нужен.

Финальная поставка 1.0.2 обновлена из `main` 21 ноября 2026 и включает
исправление `5bb9411`. При добавлении товара «Добавляем...» показывается
только на его кнопке. Повторное добавление этого товара блокируется на время
запроса, другие товары остаются доступны. После успеха или ошибки кнопка
восстанавливается. Подтверждены 14/14 тестов, TypeScript и production-сборка;
исправленный React bundle опубликован на существующем Alpic endpoint.
React загружается с сервера, поэтому версия манифеста плагина остаётся 1.0.2.

1. Распакуйте `shopping-cart-handoff-1.0.2.zip`.
2. ChatGPT: выполните `INSTALL-CHATGPT.md`. Если ZIP не активирует MCP, создайте
   собственное подключение к тому же серверу и добавьте Skill в созданный плагин.
   Чужой App ID не нужен.
3. Codex: выполните `INSTALL-CODEX.md`. Папка `codex-marketplace` устанавливает
   плагин с MCP и Skill. В терминальном CLI React UI не обещается.
4. В новом чате выберите плагин и попросите: «Покажи каталог. Не меняй корзину».
5. Затем: «Покажи подробности первого товара», «Покажи общую демо-корзину»,
   «Прочитай установленный shopping-assistant и процитируй последнее правило
   Important rules. Не вызывай read_skill».

Каталог возвращает до 20 товаров. Scenario Modeler открывается кнопкой
«Спланировать покупки» в React и не меняет корзину. Запросы «добавь», «измени
количество», «удали» изменяют общую демо-корзину. Оплата не реализована.

Статус проверок — `VALIDATION.md`. Карточка плагина сама по себе не доказывает
доступность инструментов. Чистая установка на вашем аккаунте и мобильный клиент
требуют проверки. При «Использовать на компьютере» начните с настольного клиента.
